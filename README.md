# 🚀 Library Management

This Python application exposes a locally available API. Follow the steps below to run it locally.
It's for study purposes.

---

## ⚙️ Installation

1. Clone this repository or place the files in a folder.
2. Open a terminal at the root of the project.
3. Install the necessary dependencies with :

```bash
pip install -r requirements.txt
```

---

## ▶️ Launch the application

Start the server with :

```bash
python main.py
```

---

## 🌐 API access

- API : [http://localhost:8000](http://localhost:8000)
- Interactive documentation (Swagger): [http://localhost:8000/docs](http://localhost:8000/docs)

---

## 🧰 Prerequisites

- Python 3.x
- pip
